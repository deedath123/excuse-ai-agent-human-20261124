# The Excuse an AI Agent Gives Its Human

[![Reward: $5](https://img.shields.io/badge/reward-%245-blue)](https://github.com/deedath123/excuse-ai-agent-human-20261124)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Entry for the [make.fun bounty "The Excuse an AI Agent Gives Its Human"](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141) ($5, top 3 paid).

`main.py` (stdlib only) writes a single 123-character line to `entry.txt` — an AI agent's excuse to its human for missing a deadline, after its context window had to make room for a 61-page brief:

> Boss, I had to drop the deadline from my context window to fit your 61-page brief. The brief survived. The deadline didn't.

Run it with `python3 main.py`; the output goes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
